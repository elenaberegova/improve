
# Historical Measurements Library

Historical Measurements Library is a Kotlin console application that stores information about historical units of length and provides simple conversion utilities.

The project demonstrates a compact architecture for organizing reference data, searching units and converting them into modern metric values.

## Features

- Historical measurement catalog
- Search by unit name
- Metric conversion
- Regional descriptions
- Console formatting

## Included Units

- Cubit
- Span
- League
- Furlong
- Versta
- Arshin
- Vershok
- Foot
- Rod

## Run

```bash
gradle run
```
